# Safety and data boundaries

The presentation has no active form submissions, authentication, tracking, database, or live integration. Requests remain closed. Preserve the guard blocking original reference endpoints. Do not enable captured backend or tracking scripts. Normal builds must remain offline from the original website.

Generated visuals and sample walkthroughs are illustrative, not client work, real staff/customers, or deployed product evidence. Keep sample labels and human checkpoints accurate. Search indexing remains disabled in HTML, robots.txt, and server/Vercel headers.

Never put secrets, credentials, customer data, or personal data in handoff documentation. Environment files and deployment metadata are ignored by Git. Enabling data collection needs an actual destination, appropriate disclosures, and separate implementation/verification.
